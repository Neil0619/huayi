# Huayi Store 商店清单与数据披露草案

## 清单文案

**名称**：划译 Huayi

**简短说明**：网页与 YouTube 英文划词翻译、语境分析和端到端加密的本地生词本；使用你自己的
OpenAI 或 DeepSeek 密钥。

**单一用途**：帮助中文英语学习者在当前阅读或观看语境中理解主动选择的英文，并把用户主动保存
的词条留在加密本地生词本。不得在清单中宣称账户同步、开发者云、零数据外发或官方第三方合作。

## 权限理由

| Manifest 能力                                 | 商店理由                                                                                   |
| --------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `http://*/*`、`https://*/*` Content Script    | 让用户在阅读页面获得一致的主动划词体验；安装与首次运行显著披露，并提供全局和精确站点停用。 |
| `storage`                                     | 保存非敏感设置、同意回执、DeviceVault key envelope 和加密记录；限制为可信扩展上下文。      |
| `unlimitedStorage`                            | 权威本地生词本可随语境记录增长，避免容量驱逐；用户可搜索、删除和导出词表。                 |
| `alarms`                                      | 恢复用户已经启动的耐久欧路导入/导出任务；不用于遥测或无任务轮询。                          |
| OpenAI、DeepSeek、欧路三个固定 HTTPS API host | 只由 Service Worker 直连用户选择的模型或欧路；网页消息不能指定 URL、Header 或请求体。      |

不申请 `tabs`、`activeTab`、`scripting`、`nativeMessaging`、隐身模式、可选权限或任意第三方 endpoint。
Popup 只使用基础 active tab ID 把无 URL 的站点请求转给已注入 Content Script。

## Chrome Web Store 数据披露映射

提交问卷时采用保守口径，并与实际问卷字段逐项复核：

- 处理 **Website content / 用户提供内容**：用户主动选择的文本、必要上下文和主动保存的词条语境；
- 处理 **Authentication information**：用户提供的 Provider/欧路凭据，仅在本地加密并发送给对应
  接收方；
- 目的仅为 **App functionality**；不用于广告、分析、画像、信用或向数据经纪商出售；
- Huayi 开发者没有接收端；为提供功能，会把数据直接传输给用户明确选择并同意的第三方，因此
  不能回答或宣传“数据从不共享”；
- 不收集浏览历史、URL、页面标题、完整模型输出、健康信息、支付信息或精确位置；
- 无账户、默认遥测或自有后端。

如商店问卷定义与本草案不同，以提交时可见的官方定义为准，并由人工留下截图证据。任何答案变化
都必须回查 Manifest、首次联网披露和[隐私政策](./privacy-policy.md)。
