# 语见 · Seen & Said Store 商店清单与数据披露草案

本草案面向 `production` profile 的未来 Chrome Web Store 版本，固定连接
`https://api.seen-said.cn` 和 `https://app.seen-said.cn/app`。它不是无云端的 `release` 兼容包文案。

## 清单文案

**名称**：语见 · Seen & Said

**Slogan**：Turn what you see into what you can say.

**简短说明**：网页与 YouTube 英文划词翻译、语境分析和本地生词管理；可连接语见账号继续学习，
或使用自己的 OpenAI、DeepSeek 密钥。

**单一用途**：帮助中文英语学习者理解当前阅读或观看语境中主动选择的英文，并将这些内容整理为
可复习、练习的学习资料。网页划词、YouTube 字幕辅助、生词管理和词典回填均服务于这一用途。

**详细说明草案**：

- 主动选择网页或 YouTube 英文字幕，获得翻译和语境解释，可保存到本机生词本。
- 基础本机功能无需语见账号；模型查询需要相应联网同意及可用服务。连接语见账号后，可按账号
  偏好使用平台额度、加入待学习区，或把以后收藏的本机生词复制到 Web。云端功能需要可用账号，
  当前服务采用邀请制；BYOK 费用由用户与对应供应商结算。
- 欧路导入/导出与扇贝回填需要分别同意和启用。扇贝每批最多预填 100 个不同目标词头，最终添加
  由用户亲自点击；账号共享可协作维护回填进度。
- 提供全局和逐站关闭、凭据删除、生词删除和词表导出。账号内容可在 Web 导出或删除。
- 凭据与本机生词使用设备端加密；设备密钥与密文均在同一 Chrome Profile 中，不能防护整个
  Profile 泄露。云端学习内容由服务器处理，产品不提供端到端加密保证。
- “自动上传错误诊断”默认关闭；用户独立开启并连接账号后，扩展可自动上传脱敏错误信息。

## 权限理由

| Manifest 能力                             | 商店理由                                                                                           |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 所有 HTTP(S) 页面的 Content Script        | 在当前阅读页面提供主动划词体验和逐站控制；提供全局及精确站点停用，不自动上传完整页面。             |
| YouTube 固定匹配地址与 MAIN/isolated 脚本 | 在当前顶层播放器提供字幕选择与播放状态辅助；脚本随扩展打包。                                       |
| `storage`                                 | 保存设置、同意回执、设备密钥、加密凭据、生词、账号会话和任务状态；限制为可信扩展上下文。           |
| `unlimitedStorage`                        | 避免增长中的本机生词与离线任务受到常规存储配额限制；提供删除和词表导出，不承诺无限磁盘或完整备份。 |
| `alarms`                                  | 恢复已启动的耐久任务；主动开启回填后的欧路每日检查、云端刷新，以及用户开启诊断后的错误补传。       |
| OpenAI、DeepSeek、欧路固定 HTTPS API host | Service Worker 直连用户选择并同意的模型或欧路；对应凭据仅发送给对应服务。                          |
| `https://api.seen-said.cn/*`              | 账号配对、平台查询、学习采集、生词复制、云端词典/回填和独立同意后的错误诊断。                      |

扇贝回填另有仅匹配顶层 `https://web.shanbay.com/*` 的随包内容脚本，运行时仍限定精确收藏页。

不申请 `tabs`、`activeTab`、`scripting`、`nativeMessaging` 或隐身访问；不执行远程托管扩展代码。
站点操作利用基础 tab ID 与已注入 Content Script，不通过 tabs 权限读取 URL。扇贝使用固定收藏页
和页面交互，不由后台调用任意扇贝 API。远端模型响应作为数据处理，不作为扩展代码执行。

## Chrome Web Store 数据披露映射

按最终 ZIP、产品界面和公开隐私政策逐项核对 Dashboard。以下是保守的填写依据，不能选择“不处理
任何用户数据”；Google 明确要求本地处理的数据也披露。见
[用户数据 FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)及
[隐私字段说明](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy/)。

| 数据类别                            | 实际处理与填写依据                                                                                                                                                                       |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Website content / 用户提供内容      | 主动选择的文本、有界上下文、生词、学习意图及回填词头。云端采集可按用户已开启的账号偏好自动触发，不能写成每次均另行确认。                                                                 |
| Authentication information          | 本机 Provider/欧路凭据，以及语见账号配对和会话认证信息。BYOK/欧路密钥不发送给语见；账号认证由语见服务处理。                                                                              |
| Personally identifiable information | 连接账号涉及邮箱、账号及设备关联信息；不能因为邮箱登录发生在 Web 就笼统声明“无账号资料”。                                                                                                |
| User activity（按问卷定义复核）     | 功能所需学习/任务进度、模型用量及可选错误诊断，目的为功能和故障排查；没有广告行为画像。                                                                                                  |
| Web history（按问卷定义复核）       | 不建立或上传浏览历史；本机仍处理当前站点以执行精确站点策略，并识别 YouTube/扇贝页面。不能把“不向模型发送 URL”写成“从不处理网址”。若问卷覆盖此类本机域名/页面处理，应据实勾选并解释用途。 |

用途限于所述学习功能、账号安全、额度与故障处理；不出售，不用于广告、画像、信用或保险判断。
不主动采集支付信息、健康信息或精确位置。用户选中的正文可能自行包含个人内容，因此不能保证
所有 Website content 永远不含敏感信息。最终勾选项、用途认证和权限理由须留存人工核对截图。

### 接收方、触发与保留

- **本机 BYOK**：主动查询把最小输入发给用户选择的 OpenAI/DeepSeek；语见不接收密钥或该次
  精简结果。独立开启的云端采集/复制仍可能向语见发送学习内容，两条路径不自动互相回退。
- **语见 API 与平台服务**：平台额度查询经语见 API 交给 DeepSeek；查询正文及精简结果最多保留
  一小时。学习采集、云端生词和练习按账号数据规则保留至删除。Supabase/Vercel 提供身份、存储和
  托管，Resend 提供账号邮件；账号当前未启用 Google 登录。
- **欧路与扇贝**：欧路导出可能包括词头和允许的原句；回填仅提取词头。扇贝只预填目标词头，
  每批由用户最终提交。主动开启回填后默认本地 08:00 检查欧路，浏览器恢复后补查；账号回填默认
  每 15 分钟刷新。首次包含已同意来源的已有词。
- **账号回填共享**：有效账号连接且用户确认共享后，欧路/本机词头、来源类别、必要设置与进度
  上传语见 API，并读取该账号云端生词；不上传欧路/本机解释和语境，也不自动创建云端学习项。
  各设备须使用同一扇贝账号，语见不能验证扇贝身份或读取其完整词表。
- **可选错误诊断**：独立开启并连接账号后自动上传错误码、阶段、状态码、耗时、版本和关联编号；
  不含正文、URL、模型回答、Key 或原始异常。待上传记录最多 100 条、256 KiB、24 小时；关闭或
  退出账号清除本机待上传日志，服务端保留 30 天，账号删除时清理。

本机删除、卸载或断开账号不会删除已经产生的云端/第三方副本。账号删除按
[账号数据权利](../cloud-v1/account-data-rights.md)处理；欧路和扇贝副本由对应第三方账号管理。
停用回填保留已有进度；共享后断开须重连原账号继续，换账号不会迁移原账号历史。本机词表导出是
一词一行明文，不含完整语境记录，不能作为完整恢复备份。
