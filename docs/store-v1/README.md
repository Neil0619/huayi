# 语见 · Seen & Said Store Extension

此目录记录尚未发布的纯 MV3 Store Extension，包括 Cloud V1 查询入口、四套明亮外观、
Provider、DeviceVault、欧路/扇贝、隐私披露和 Chrome 审核边界。当前候选仍处于开发与真实平台
验收阶段，不得解释为已发布或已达到商店上架标准。

外观固定为 `moon | silver | champagne | porcelain`，默认 `silver`；选择仅保存在当前扩展设备。
`pearl | parchment` 继续是独立词卡材质，不再表示整页主题。唯一视觉权威见
[语见 C/G/H/I UI 设计系统](../cloud-v1/seen-said-ui-design-system.md)。
