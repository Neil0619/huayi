# 语见 · Seen & Said Store 隐私政策

> Turn what you see into what you can say.

文档修订日期：2026-09-16（公开版本须在发布前核对）

## 适用范围与单一用途

本政策适用于语见 Store Chrome 扩展。扩展的单一用途是在用户主动选择英文文本时提供翻译、
语境分析、YouTube 英文字幕辅助、本地生词管理与用户主动开启的扇贝回填。基础本机功能无需语见
账号；具备云端能力的构建可连接账号并共享回填进度。扩展默认不进行遥测。

## 处理的数据

- **网页内容**：只有在用户主动分析时，才处理选中文本和完成该次分析所需的有界上下文。不会把
  URL、页面标题或浏览历史加入模型请求。
- **认证信息**：用户自行输入的 OpenAI、DeepSeek 和欧路凭据。凭据在设备上加密保存，不会发送
  给语见开发者；每个凭据只发送给其对应的第三方服务。
- **本地学习数据**：规范词条、原句、语境释义、来源类别和时间。不会保存 URL、页面标题或完整
  模型结果。
- **设置与回执**：Provider、站点开关、YouTube 模式，以及对各类外部数据传输说明的版本化同意。
- **回填数据**：用户主动开启后的欧路、本机收藏和当前账号云端生词的词头、来源类别、回填目标、
  成功/待处理/结果未知进度、检查时间及必要回填设置。它们不包含欧路或本机词的解释、原句、网页
  URL、标题或模型结果。

## 数据用途与外部传输

语见不出售这些数据，也不将其用于广告、信用或保险用途。为完成用户明确请求，扩展可能连接：

- 用户选择的 OpenAI 或 DeepSeek：发送选中文本、必要上下文和分析指令；API 使用由用户账户计费；
- 欧路：在用户独立同意、启用并开始导入/导出或主动开启回填检查后，发送欧路凭据和固定分页请求；
  导出还可能发送词头及允许的语境字段。回填只提取词头；默认设备本地时间每天 08:00 分页检查，
  浏览器恢复后补查，用户也可手工检查；
- 扇贝：主动开启回填后，把每批最多 100 个不同目标词头预填到收藏页。每一批最终添加始终由用户
  亲自点击；明确失败只尝试一次本地词元候选，仍需用户提交。结果未知须人工核对后重试；
- 语见账号 API：仅在支持云端的构建、有效账号连接及用户确认共享后，上传欧路/本机词头与回填
  进度以供跨设备协作，并读取该账号已有云端生词。默认每 15 分钟刷新，首次开启包含已有来源词。
  该过程不上传欧路/本机解释或语境，不自动创建云端生词或学习项，也不调用模型。

未连接账号时回填进度保留在本机。账号共享需要各设备使用同一个扇贝账号；语见不能读取或验证
扇贝账号身份或其完整词表。正式商店候选使用 production 构建并连接生产 API；Hosted 本地验收使用独立账号和固定验收 API；本政策文档不代表这些版本已经发布或通过真实网站验收。

同意某一接收方不会自动同意其他接收方。Provider 失败不会自动切换或重发付费请求。语见与
OpenAI、DeepSeek、欧路、扇贝、Google 或 YouTube 均无隶属、认可或官方合作关系；第三方对收到
数据的保存和删除适用其自己的条款与隐私政策。

## 保存、保护与删除

凭据和生词数据在浏览器端使用 AES-256-GCM 加密。随机设备密钥保存在限制为可信扩展上下文的
Chrome 本地存储，重启、更新、禁用或重载后自动可用。取得整个本地 Chrome Profile 或可信扩展
上下文的攻击者可能同时取得设备密钥与密文，因此本设计不防护本地 Profile 整体泄露。产品没有
本地解锁密码或备份密码。回填本机状态也加密保存；共享回填状态由语见云端按账号隔离，不适用
“仅本机可读”的保证。

本机历史已共享到账号后，断开连接不会恢复独立本机回填，须重连原账号继续。改连其他账号不会
迁移原账号历史；在新账号开启时，现有本机词头成为排除基线，不以本机来源上传，之后新增的不同
词头仍会发现。新账号自己的云端词和已同意的欧路来源独立检查。

用户可以在设置页删除本地词条、删除凭据、撤回接收方同意、导出一词一行的明文词表或清除扩展数据。卸载
扩展会由 Chrome 清除扩展自身存储；用户另行保存的词表文件不受卸载影响。词表不包含语境等完整
学习记录，不能用于恢复本地生词本。账号数据导出 format 5 包含已共享回填的设置、来源、目标成功
证据和批次公开状态，不含租约 token、设备标识或未共享本机库；账号导出和删除按
[账号数据权利](../cloud-v1/account-data-rights.md)处理。

停用回填会停止新发现和认领，保留已有进度。本机词条删除、清除扩展数据或卸载不删除云端回填
账本；删除语见账号会清除账号回填数据。以上操作均不会删除已经发送给欧路或扇贝的副本，用户应
通过对应第三方账号请求删除。

## 用户选择与风险

全局开关和精确站点开关可以停止页面功能；各接收方同意与启用仍独立控制外发。明文
导出会失去本地加密保护，扩展会在导出前要求额外风险确认。任何联网传输都可能受第三方可用性、
费用和政策变化影响。

## 政策更新与联系

若处理字段、目的或接收方扩大，语见会更新政策和对应披露版本，并在再次发送前重新取得所需
同意。问题、数据处理请求或安全报告可提交至
[语见 GitHub Issues](https://github.com/Neil0619/huayi/issues)。正式商店提交前，必须把本政策发布
到无需登录即可访问的固定 HTTPS 地址，并在商店清单中填写该地址。
