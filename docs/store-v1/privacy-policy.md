# 语见 · Seen & Said Store 隐私政策

> Turn what you see into what you can say.

生效日期：2026-08-11

## 适用范围与单一用途

本政策适用于语见 Store Chrome 扩展。扩展的单一用途是在用户主动选择英文文本时提供翻译、
语境分析、YouTube 英文字幕辅助和本地生词管理。语见不提供账户、自有云后端、订阅或默认
遥测服务。

## 处理的数据

- **网页内容**：只有在用户主动分析时，才处理选中文本和完成该次分析所需的有界上下文。不会把
  URL、页面标题或浏览历史加入模型请求。
- **认证信息**：用户自行输入的 OpenAI、DeepSeek 和欧路凭据。凭据在设备上加密保存，不会发送
  给语见开发者；每个凭据只发送给其对应的第三方服务。
- **本地学习数据**：规范词条、原句、语境释义、来源类别和时间。不会保存 URL、页面标题或完整
  模型结果。
- **设置与回执**：Provider、站点开关、YouTube 模式，以及对各类外部数据传输说明的版本化同意。

## 数据用途与外部传输

语见开发者不接收、出售或用于广告、信用、保险等用途处理上述数据。为完成用户明确请求，扩展
可能直接连接：

- 用户选择的 OpenAI 或 DeepSeek：发送选中文本、必要上下文和分析指令；API 使用由用户账户计费；
- 欧路：在用户分别同意、启用并开始导入或导出后，发送欧路凭据、固定分页请求、词头及允许的
  语境字段；
- 扇贝：在用户分别同意并启用后，把有界词条批次呈现在扇贝页面；最终提交始终由用户点击。

同意某一接收方不会自动同意其他接收方。Provider 失败不会自动切换或重发付费请求。语见与
OpenAI、DeepSeek、欧路、扇贝、Google 或 YouTube 均无隶属、认可或官方合作关系；第三方对收到
数据的保存和删除适用其自己的条款与隐私政策。

## 保存、保护与删除

凭据和生词数据在浏览器端使用 AES-256-GCM 加密。随机设备密钥保存在限制为可信扩展上下文的
Chrome 本地存储，重启、更新、禁用或重载后自动可用。取得整个本地 Chrome Profile 或可信扩展
上下文的攻击者可能同时取得设备密钥与密文，因此本设计不防护本地 Profile 整体泄露。产品没有
本地解锁密码或备份密码。

用户可以在设置页删除本地词条、删除凭据、撤回接收方同意、导出一词一行的明文词表或清除扩展数据。卸载
扩展会由 Chrome 清除扩展自身存储；用户另行保存的词表文件不受卸载影响。词表不包含语境等完整
学习记录，不能用于恢复本地生词本。本地删除或
卸载不会删除已经发送给第三方的副本，用户应通过相应第三方账户请求删除。

## 用户选择与风险

全局开关和精确站点开关可以停止页面功能；各接收方同意与启用仍独立控制外发。明文
导出会失去本地加密保护，扩展会在导出前要求额外风险确认。任何联网传输都可能受第三方可用性、
费用和政策变化影响。

## 政策更新与联系

若处理字段、目的或接收方扩大，语见会更新政策和对应披露版本，并在再次发送前重新取得所需
同意。问题、数据处理请求或安全报告可提交至
[语见 GitHub Issues](https://github.com/Neil0619/huayi/issues)。正式商店提交前，必须把本政策发布
到无需登录即可访问的固定 HTTPS 地址，并在商店清单中填写该地址。
