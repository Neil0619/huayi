# Huayi Store 1.0 产品规格

## 目标与边界

Store Edition 面向使用中文学习英语的 macOS 和 Windows Chrome 用户。它在网页与标准 YouTube
录播页面中提供英文划词翻译、语境解释和本地生词管理，不要求安装桌面程序，也不依赖 Huayi
账户、后端、订阅或默认遥测。

1.0 支持 OpenAI 与 DeepSeek，用户自行提供并承担对应凭据、配额与费用。每次请求在开始时锁定
一个 Provider；失败后不切换 Provider、不自动重发付费请求。每个正式版本固定已经实机验证的
模型标识，首个候选标识为 OpenAI `gpt-5.6-luna` 与 DeepSeek `deepseek-v4-flash`；未完成真实
验证前不得把候选标记为发布模型。

1.0 不包含账户系统、自有云、计费、跨设备同步、追问聊天、浏览历史、Linux、其他浏览器、
OCR、PDF 图片取词或自动点击扇贝最终提交按钮。

## 核心行为

### 分析

- 用户可对一个英文单词、短语或句子选择“翻译”或“解释”。
- ClassicParity 以 Classic Edition 0.13.0 的已确定行为为 Store 功能下限。ActionCard 依次显示解释、
  翻译，不回显选区，也不显示关闭按钮；进入分析后顶部仍可切换两个模式。最终 ResultCard 按六类严格结果呈现
  语义重点、详情行、成对信息或辨析组，并保留必要词头或短语标题；句子不重复整句，所有类型都
  不显示原句语境块。
- 单词分析进入加载态后查询本地生词状态；模型返回的规范词头与选区不同则重新核对。顶部生词动作
  原位呈现检查、可保存、保存中、已保存、重复或可重试错误；短语和句子没有该动作。
- Content Script 只发送选择与意图；Service Worker 从可信设置中补充 Provider、固定模型及目标
  语言，并在发送前再次校验所有长度和类型。
- 流式增量只是预览，只有完整结果通过公开 Schema 后才构成成功。
- 页面刷新、取消、端口断开或 Worker 中断都产生可见失败；产品不得静默重发。
- 同一次 CardSession 顶部始终提供翻译与解释切换；每个成功结果只在该会话内缓存。切换到尚未
  完成的模式时取消当前请求并只启动新模式；失败只属于对应模式，不清除另一模式的缓存。关闭词卡
  会销毁两个模式的结果与错误状态。

### 本机加密与联网同意

- 干净安装自动创建 DeviceVault，浏览器或扩展重载后分析、生词和外部词典直接可用，不设置本地密码。
- Store 1.0 不提供旧密码库或 Classic 设置包迁移 UI；新 ID 下重新录入凭据。
- 首次向每一类外部接收方发送数据前，界面必须显示接收方、发送字段和费用提示并取得主动同意。
- OpenAI/DeepSeek、欧路和扇贝分别记录带版本的同意；欧路与扇贝还必须分别显式启用。拒绝、
  撤回或停用只阻止对应外发，不影响本地保存与站点设置。

### 本地生词本

- 一个规范化 WordEntry 可包含多个 ContextObservation。
- 网页或 YouTube 保存的语境只含原句、语境释义、来源和时间；不保存 URL、标题、页面 ID 或
  完整模型结果。
- 欧路导入的词允许没有语境记录。
- 同一来源下规范化原句相同的语境视为重复；模型词元只能建议合并，不能静默改变词条身份。
- 删除是本地操作：取消尚未发送的导出，不删除欧路或扇贝中的既有数据。

当前网页生词闭环已经接通：只有通过严格公开 Schema 的单词结果会显示保存按钮，保存按钮只接受
真实用户手势，并只提交规范词头候选、原句和最长 1,000 字符的语境释义；请求不能声明来源，
Service Worker 根据经过校验的 sender URL 判定普通网页或 YouTube。重复
语境重复和密文损坏都有独立可见状态；短语和句子结果不显示保存入口。Options 可直接
搜索、分页浏览词条和语境并仅删除本地记录，也可直接下载每行一个规范词头的 UTF-8 纯文本词表。
Store 1.0 不提供加密备份、恢复或明文 JSON；词表不含语境、释义、来源和时间，不能完整恢复本地
生词本。新的网页语境保存只会为保存当时已经同意且启用的目标幂等
创建导出意图；全部目标停用时本地保存仍成功，日后启用不会静默补发旧词。本地删除先取消尚未
外发的意图，取消成功后才删除词条，不会删除远端数据。

### 欧路与扇贝

- 欧路导入由用户显式开始，可暂停、恢复并展示检查点；导入结束后不进行每日轮询。
- 欧路导出先查询再添加：已存在即形成回执，不覆盖远端解释。
- 扇贝导出生成耐久批次并定位页面操作，但最终确认和提交始终由用户完成。
- 批次支持部分成功、失败重试与词元建议；无法确认的项目保持可见，不能谎报完成。

欧路核心每次只处理一个固定大小页面或一个导出任务。页码、租约、回执和检查点都先持久化；HTTP
发生在 IndexedDB 事务之外。页 0–50 均为满页时，检查点进入 `source-limit-reached`，不会显示为
完整导入。导入保留合法 `context_line` 和远端时间，但不会把欧路的通用词典解释伪装成语境释义。
Options 显示 Authorization 配置状态、导入检查点、公开分页上限、稳定错误和导出箱，并要求用户
显式处理或重试。欧路未同意时不发起任何欧路网络请求，停用后手工处理和 Alarm 都在调用引擎前
停止。扇贝只在当前版本同意且启用后，才于
`https://web.shanbay.com/wordsweb/#/collection` 认领最多 100 个词；
划译可打开批量窗口并在空输入框中预填，但不会点击最终提交。只有真实用户点击后的新增、可验证
页面结果才能按当前租约确认；部分失败项重新排队，迟到或伪造回执不修改队列。

### YouTube

沿用 `CONTEXT.md` 中 CurrentPlayer、ActiveSourceTrack、TranslatedCaptionTrack、SubtitleSentence、
EnglishMode、BilingualMode、PauseOwnership 与 CaptionGeneration 的现有定义和失败关闭规则。用户
可选择 Huayi 字幕文本进行分析和保存生词，体验与普通网页一致。

Store 只在三个固定 HTTPS YouTube 主机的 `/watch` 录播页面运行字幕模块。设置可选择停用、默认
英文或默认双语；英文模式仍允许用户手动切换双语。只有播放器已连接、非广告、非直播、有限时长、
CC 已开启且当前轨为英文时才替换原生字幕。Huayi 英文字幕使用稳定、可选择的文本节点；真实
`mouseup` 手势产生与普通网页相同的 AnalysisEngine/Overlay 请求，完整单词结果可保存为来源
`youtube` 的 ContextObservation。Provider 和 Repository 都不会收到或保存页面 URL、标题或视频 ID。

字幕桥只短时捕获当前播放器为固定英文源轨发出的严格 `/api/timedtext` JSON3 响应，并在成功、
失败、超时或导航时恢复 fetch、XHR 和播放器状态。正文、轨道、事件和 segment 都有上限；任何
不匹配或损坏都恢复原生字幕并失败关闭。真实 YouTube/Chrome 行为仍属于发布前需单独批准的手工
验证，当前离线测试不能替代该证据。

双语交互保留两个职责不同的“中”：YouTube 原生 CC 旁的“中”单击固定或取消当前视频的双语
模式；字幕卡右上角的“中”只在按住期间临时显示中文，松开、指针取消、窗口失焦或页面隐藏后
立即恢复。若视频原本正在播放，顶部临时“中”会在首个指针或键盘来源按住时暂停，并在全部来源
释放后仅恢复该按住所拥有的暂停；原本已暂停、按住期间已由用户或媒体恢复、或已离开当前
CaptionGeneration 的视频都不会被播放。底部固定“中”不改变播放状态。控制栏重建时固定双语
按钮重新挂到新 CC 旁，不复制按钮，也不销毁仍有效的字幕面板。两个按钮的 pointer、mouse、
click 和双击事件都不能继续到播放器交互代理。

播放中的视频因有效字幕选区被 Huayi 暂停后，第一次点击播放器空白区会关闭浮层、清除选区并
恢复该视频；同一指针激活随后的原生 click 也由 Huayi 消费，不能把刚恢复的视频再次暂停。原本
已暂停的视频不会取得 PauseOwnership，关闭浮层也不会替用户播放。播放器控件、字幕文本与
Huayi UI 不属于空白区。

## 设置与错误

设置页至少提供 Provider 凭据状态、默认动作、全局开关、站点规则、YouTube 模式、
欧路凭据、导入状态、导出箱、本地生词浏览及词表导出。所有异步保存由一个边界负责 busy、成功、错误和
回滚；任何拒绝都必须进入可见错误状态，不产生未处理 Promise rejection。

当前可信 Options 页已经实现首用安全闭环：在任何模型联网前显著说明发送字段、接收方和潜在
费用，并允许授予或撤回同意；模型联网确认收进“模型与划词动作”，不再占用独立大卡。完整联网
说明和每个接收方说明使用原生折叠控件，首次同意保留在主界面，低频撤回操作收进对应说明。
用户可以选择 OpenAI 或 DeepSeek，并管理两个固定 Provider 的密钥。已有 Provider
和欧路凭据只显示“已配置”与掩码占位，不会回显。欧路和扇贝分别保留接收方、字段、费用与远端
保留语义，并提供独立的同意、启停与撤回。
本地生词管理和欧路/导出箱管理也使用可见异步错误边界。
YouTube 停用/英文/双语偏好及可关闭组合快捷键、默认动作、全局开关和站点策略已
接入严格 Settings v6。全新安装默认直接翻译；已有 Settings v6 的显式 `ask` 及旧版本迁移行为
保持不变。站点策略支持默认 allow/block、精确 hostname 与包含子域规则；Popup
只显示当前 Provider、模型联网同意、当前网站状态及单站开关，不显示任何凭据配置状态，并通过当前标签页 Content
Script 查询或切换当前 hostname 的精确规则；活动标签页变化时拒绝陈旧操作。全局开关、单站开关
和词卡材质都可从 Popup 快速调整；所有异步保存共用可见错误边界。四套明亮外观
`moon | silver | champagne | porcelain` 在 Options“常用设置”中以带名称的单选卡选择，默认
`silver`，仅保存在当前扩展设备；Popup 继承当前外观且不提供第二个选择器。两套词卡材质
`pearl | parchment` 复用同一内容结构，只切换通透与柔雾参数；ActionCard 不回显选中文本，ResultCard
按视口留白居中或夹紧并使用自身滚动，不显示 Web 工作台引导页脚，只显示必要词头或短语标题而不
显示“原文/原句语境”块。页面滚动或视口尺寸变化会关闭已失效的选区浮层。选区仍仅用于当前请求、
结果校验及用户主动保存的有界语境。

Options 使用渐进式分类而非一次铺开全部配置：默认只显示常用设置，通过可访问的分类导航切换
密钥、外部词典和本地生词；常用设置提供一个通过固定版本、无参数 Worker 消息打开的语见云端
登录入口。页头是 64–72px 应用工具栏并提供项目 GitHub 入口；持续生效的全局、
欧路和扇贝开关使用 switch，一次性风险确认仍使用 checkbox。
分类切换不得重置已经输入的表单值。Options、Popup、Shadow DOM Overlay、YouTube 与扇贝提示各自
使用 Store 包内 `primitive → semantic → component` 三层 CSS token。四套外观只覆盖 semantic
Token，不改变 DOM、布局、间距或交互；C 使用深墨蓝操作色，G 使用黛黑石墨色，H 使用深咖色，I
使用靛蓝色。全部主要文本、控件和焦点态保持 AA 对比度，并提供 backdrop-filter 不可用、
forced-colors 与 reduced-motion 降级，不加载远程字体或代码。

错误必须区分未同意、未配置、鉴权失败、限流、配额、网络、超时、无效响应、取消、版本
不匹配和本地数据损坏。错误文本不得包含密钥、原始响应、完整页面输入或环境内容。

### 未完成：诊断与反馈

1.0 后续需增加本地 DiagnosticEvent 和用户主动“反馈问题”入口。事件只允许记录扩展版本、系统与
Chrome 大版本、时间、随机事件 ID、稳定错误码，以及 `provider-sse`、`model-json`、
`model-schema`、`public-result-schema`、`content-protocol`、`rendering` 等固定失败层级；禁止记录
选区、网页内容、URL、标题、凭据、模型正文和原始响应。默认自动远程上报继续禁止。

只有在具备明确接收后端、保留期限、删除机制、更新后的隐私政策和产品内显著披露，并取得用户
单独明确同意后，未来版本才可提供可选的自动错误上报；该能力不属于当前 1.0 实现。
