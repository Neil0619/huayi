# 安装时全站权限配合显式联网同意和零开发者遥测

Store Edition 安装时申请所有 HTTP(S) 页面上的 Content Script 权限，以保证划词体验一致；首次
向 Provider 或词典发送数据前，产品必须说明接收方和字段并取得同意。开发者不接收遥测，用户
仍可按站点关闭 Huayi；相比可选站点权限，这一决定增加商店审查和信任成本，因此固定外部主机、
最小权限、站点控制和显著披露都是发布门槛。

## Considered Options

按站点临时授权权限更小，但会把首次使用变成重复授权流程，并削弱划词行为的一致性。
