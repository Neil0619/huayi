# Store 只提供一词一行的词表导出

## Context

完整加密备份、恢复与明文 JSON 把密码、文件校验、全库替换和高风险确认暴露给用户，但当前产品只
需要让用户带走生词词头。完整恢复能力会显著增加设置复杂度和损坏数据覆盖风险。

## Decision

Store 1.0 删除加密备份、恢复和明文 JSON 的产品接口与实现，只保留 `WordListExport`。导出文件为
UTF-8，按词条身份去重并按字母顺序排列，每行一个规范词头，文件末尾保留换行，文件名为
`huayi-words-YYYY-MM-DD.txt`。词表不含语境、释义、来源或时间，也不能导入或完整恢复生词本。

## Consequences

用户获得直接、无确认步骤的明文词表，但必须接受扩展卸载或数据损坏后无法从该文件恢复完整学习
记录。内部逐记录加密、索引 HMAC 与 CAS 写入边界保持不变；Repository 不再暴露备份密码、全库
替换或完整明文序列化接口。
