# 密码和恢复码分别包装同一个 Vault 密钥

Store Edition 使用随机数据加密密钥保护凭据和生词本，再分别用密码派生密钥与一次性恢复码派生
密钥包装它。相比直接用密码加密所有记录，这允许修改密码而不重写全部数据，也提供无账户恢复；
代价是用户必须确认并自行保管恢复码，Huayi 开发者无法代为恢复丢失的密码和恢复码。

## Consequences

恢复流程只重设密码包装，不导出或显示 Provider 凭据；原始恢复码不持久化。初始化与每次显式
轮换都以“恢复未确认”开始，只有恢复码能解出当前解锁 DEK 时才标记确认。用户可在解锁后轮换
已经确认或未确认的恢复码；轮换保持 DEK、密码包装和全部密文记录不变，并让旧恢复码立即失效。
