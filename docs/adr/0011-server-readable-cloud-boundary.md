# 使用 Supabase 与 Vercel 建立服务端可读的云端边界

Cloud V1 使用 Supabase Auth/Postgres 和两个独立 Vercel 项目承载 Web 与 Hono API。业务写入只经
版本化 API，RLS 作为纵深防御；用户内容通过 TLS 传输、在数据库侧加密，但不采用端到端加密，
因此服务端在提供分析、整理和练习时可以读取内容。相比纯本地或 E2EE，这一选择换取跨设备权威、
服务端配额和未来客户端复用，并承担账号、删除、导出、供应商和隐私披露责任。

## Consequences

本 ADR 取代 ADR 0004 中“开发者不接收用户内容”的部分，但保留全站能力、显著联网同意、最小权限
和用户站点控制。运行日志不得记录正文、标题、答案、完整模型结果、凭据或隐藏推理；管理员界面也
不得提供正文浏览能力。首次把网页内容发给 Huayi API 前必须取得新的明确同意。
