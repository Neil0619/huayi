## 故障与修复

用户报告桌面打开器闪过红色错误。直接运行已安装入口、运行快捷方式目标及参数、由 Windows
shell 启动实际桌面 `.lnk` 都成功打开本机网页，原红色错误未复现，原因仍未确认。

随后实际点击「选择原视频」，页面停在等待选片，用户确认没有看到文件窗口。
对本次文件选择进程自身进行临时诊断，确认已进入 `ShowDialog`，对话框位于当前桌面，
可见且未被系统隐藏，但不是前台或置顶窗口，被 Chrome 遮住；隐藏终端也没有独立可见入口。

修复给模态文件对话框设置临时、透明、不显示任务栏图标的置顶所有者。
选择、取消或异常退出时通过 `finally` 释放对话框和所有者，不留下常驻置顶窗口。
控制台仍隐藏；原文件路径通过既有 UTF-8/base64 通道返回，配置、缓存和扩展不变。
