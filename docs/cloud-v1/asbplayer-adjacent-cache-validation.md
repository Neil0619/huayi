## 实现与使用

- 新缓存位于原视频所在目录的 `缓存视频` 文件夹，保留原片名和集数，增加
  `.浏览器.mp4`、`.英语.轨道2.srt` 等用途后缀。只有小型校验记录使用内部标识。
- 完整旧缓存可复制迁移，避免重新转码；原视频、旧缓存和已有同名文件均保留。
  同名冲突产生 `(2)` 等编号。迁移保留两处副本，旧副本需用户确认后自行清理。
- 首次授权读取该缓存目录，后续同目录换片复用目录句柄。浏览器只保存句柄，
  不在 IndexedDB 存储另一份整集视频；目录权限被收回时明确要求重新授权。
- 使用磁盘 File 引用交给官网文件输入控件，取消原来的整视频 HTTP fetch/blob。
  视频 HTTP 入口返回 410；只有选中字幕通过该接口传入。导入前仅校验元数据及首尾抽样。
- 打开器保持本机 origin；重复启动使用随机挑战验证原进程，退出重启后轮换会话令牌。
  不把目录句柄或缓存路径交给官网，不增加扩展 Manifest 权限。
- 实测发现换片请求发出后按钮仍短暂可用。先以挂起请求的浏览器断言复现失败，
  再修复为点击选片后立即禁用学习、选片、字幕和退出按钮，避免导入上一集。

完整步骤与磁盘占用说明见 [Windows 原视频打开器](asbplayer-local-opener.md)。
