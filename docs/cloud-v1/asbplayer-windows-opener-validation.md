## 修复与使用变化

1. 本机打开器只读原文件，视频流复制，必要时把 AC-3/DTS 等音轨转换为 AAC；提取内嵌文字字幕。
   同一原文件复用已完整发布的缓存，失败不发布半成品，损坏缓存保留后重新准备。
2. 有唯一相邻中英双语字幕时预选它，否则优先内嵌英文。学习层按完整字幕预选明确的中英文轨道；
   歧义仍需人工选择，开始学习仍保留一次确认，不把文件名当成语言内容保证。
3. 播放器新增「打开另一个视频」，返回打开器换片。新导入成功后结束上一轮由打开器创建的播放器，
   防止双重播放；已导航去其他网站的窗口不关闭。
4. 英文字幕中的 `[♪♪♪]` 曾使整份英文轨道无效。已按 TDD 修复：符号 cue 保留原字幕，
   英文对白恢复学习；纯符号、纯中文不会被当作英文学习轨道。
5. 本机 HTTP 服务只监听回环地址，随机令牌、准确 Host/Origin、受限选定文件 ID；
   官网导入校验 opener/origin/nonce，未增加 Chrome 权限，也未修改 Classic Native Host。

使用与安全边界详见 [Windows 原视频打开器](asbplayer-local-opener.md)。
