## 权限与必要性

| 权限或地址                           | 用途                                                                                     |
| ------------------------------------ | ---------------------------------------------------------------------------------------- |
| `storage`                            | 保存设置、同意状态、加密凭据、会话和耐久任务。                                           |
| `unlimitedStorage`                   | 保护逐渐积累的本机词库和离线任务，避免常规存储配额与驱逐；不代表无限物理磁盘或备份承诺。 |
| `alarms`                             | 恢复用户已启动的配对、待提交和词典任务；不进行无任务遥测。                               |
| `api.openai.com`、`api.deepseek.com` | 直连用户明确选择的 BYOK 服务。                                                           |
| `api.frdic.com`                      | 用户明确发起的欧路词典任务。                                                             |
| `api.seen-said.cn`                   | 同意并登录后的配对、平台查询、学习采集、单词复制和账号任务。                             |
| `http://*/*`、`https://*/*` 内容脚本 | 在阅读页面主动选择英文后显示工具栏，支持全局和逐站停用；不自动读取完整页面或浏览历史。   |
| YouTube 的三个固定匹配地址           | 在顶层播放器提供可选择字幕和播放状态恢复。                                               |

固定 Web 链接只是打开学习工作台，不是远程代码来源。

## 四类数据动作

三项账号偏好决定查询路径、是否自动采集学习意图和是否复制以后收藏的本机生词。平台与 BYOK
不自动互相回退，使用本机 Key 不会免除用户独立开启的云端学习动作。

| 动作          | 触发、接收方与保留                                                                                                                                |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| BYOK 查询     | 用户主动查询；最小英文直达本机选择的 OpenAI 或 DeepSeek。Key 保存在 DeviceVault，语见服务端不接收 Key 或该次精简结果。                            |
| 平台查询      | 用户主动查询且账号选择平台额度；语见 API 与 DeepSeek 接收最小英文，正文和精简结果最多保留一小时，之后只保留无正文用量账本。                       |
| StudyCapture  | 手动加入或按账号偏好自动加入原始学习意图；只向 Web 保存原文与必要上下文，不提交插件精简结果、Key、URL、页面标题、视频 ID 或完整页面。保留至删除。 |
| CloudWordCopy | 本机词库独立保存；用户开启以后新词复制或确认批量导入时，创建独立的 Web 单词副本。换号不清空本机词库，云端副本可独立删除。                         |

正式站使用邮箱和邀请制，Google 登录未启用。账号和学习内容由 Supabase 与语见 API 处理，系统邮件
由 Resend 发送。Web 深度分析与练习使用 DeepSeek，计入账号额度，内容按账号数据规则保留。
语见不是端到端加密产品，服务器能够读取为提供功能而保存的学习内容；不用于广告、画像、信用判断或出售。

欧路只在显式任务中接收词头和可选原句，欧路凭据由插件直达欧路；扇贝只接收词头且最终提交由用户
点击。notes、标题和来源不发送给词典服务。

## 控制与删除

撤回数据联网同意会停止平台查询、StudyCapture、CloudWordCopy 和云端词典任务，并清除尚未提交的
账号绑定正文。本机 BYOK、本机词库和词典仍按各自同意工作，已有云端数据可以导出或删除。
待提交箱最多 20 条、5 MiB、7 天过期。用户可请求完整账号导出，私有文件 ready 后 24 小时过期，签名
下载地址最长 15 分钟。删除账号立即撤销会话，主数据库内容在 24 小时内删除。
供应商备份的保留与恢复限制见[正式站隐私说明](./privacy-policy-production.md)。

运行日志与管理页不提供正文浏览。所有第三方名称仅说明兼容或接收方，不表示官方合作或认可。
后续如提交 Chrome Web Store，仍需按当时 Dashboard 完成人工披露和审核；本文件不代替商店发布回执。
