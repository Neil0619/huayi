# 原文解析的阅读层次

2026-09-08，影响范围为 shared Web UI。

原页面将 `understandingZh` 和 `translationZh` 连续放在同一层级。两者本应分别承担理解提示和自然
译文，但已有模型结果常用近义句填充两者，因而看起来像重复翻译。此外，容器类名与既有样式不一致，
教学点也缺少依据、解释和例句之间的视觉分隔。

现在顶部只直接展示一份“自然译文”，理解提示和语境保留在默认收起的“理解与语境补充”中。
不根据相似度删改历史记录，也不改变保存、编辑或选择学习候选的行为。

逐句解析使用带序号的原文展开入口。展开后显示本句译文，以及按结构、语法、表达、使用提醒分组的
教学卡。每张卡区分原文依据、解释、易错提醒和明确标注的“生成示例”；缺失可选字段时省略对应区块。
短语结果同时展示既有的搭配、语域和使用提醒。

原文依据只有在模型提供的文字是对应原文的精确连续子串时才作为引用显示。大小写和兼容字符不得
改变引用含义；例如不能把 `US` 显示为 `us`，或把 `10²` 显示为 `102`。不符合要求时保留解释及
生成例句，不伪造原文。标题与精确引用相同时合为一处突出显示，避免相同英文紧挨着出现两次。
这里没有新增 Markdown/HTML 注入入口。

布局沿用现有主题 token。390px 与 1440px、四种主题均检查卡片分层、原文引用侧线、无横向溢出，
以及原生展开控件的 Enter/Space 操作。单元回归覆盖两张重复译文截图、旧结果可选字段、短语内容
和不准确的原文引用；相关类型、构建、格式及 lint 检查另行记录。

展示验收独立于模型教学质量。本变更不调用模型、不重写既有解析；提示词实验和真实调用结果保存在
本地忽略的评测 artifacts 中，不能用页面测试通过替代生成内容的语义验收。正式上线仍需完成最终
候选的统一门禁。
