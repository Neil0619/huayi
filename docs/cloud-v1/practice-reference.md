# 造句参考表达与 Hosted 反馈修复

本次范围为 Web/API。参考表达供完全不知道如何开始的学习者按需查看；默认不展开，也不自动调用模型。
用户仍负责输入自己的句子、提交和自评。

## 页面行为

- 在中文任务和作答框之间放置「没思路？先看一个参考」卡片，以及「查看参考表达」按钮。
- 首次点击前说明会使用平台额度。生成期间可以继续编辑草稿；提交按钮暂时禁用，防止与反馈生成争用。
- 准备完成后展开一个完整英文例句、中文意思和简短用法。它是按当前题目生成的参考，不冒充来源原句。
- 收起后再次展开复用保存的内容，不重新计费。不提供自动填入或自动提交。
- 按需提示模式下，首次成功查看参考同时记录本轮查看英文提示的事实；重写回合需要再次显式查看。
- 暂停、返回列表或离开账号页面只停止当前订阅。恢复时读取已保存状态；提交回执不确定时保留同一请求和幂等键。
- 查看记录已保存但网络回复丢失时，重试同步已保存的练习版本和提示事实；同轮重新读取不改变用户焦点。
- 旧会话只有在能证明学习项未在会话创建后被编辑时才支持参考；无法确认时保留原草稿和正常作答。

## 服务端权威与边界

`sentence-reference` 是既有 `/v2/learning-tasks` 的新命令，只接受 session ID、业务版本、控制版本和回合序号。
题目、目标表达/句型及模式由服务器加载。草稿、用户身份、来源网址、凭据、配额和内部标识不传入模型。

- `GET /v2/practice/sessions/:id/reference`：同账号读取 readiness；本轮未查看时正文为 `null`。
- `POST /v2/practice/sessions/:id/reference/reveal`：既有认证与 CSRF 边界；版本校验、幂等回执、查看事实同事务提交。
- GET、任务事件和预览均不能提前暴露未查看的参考英文；响应设置 `no-store`。
- 参考依次走既有 quota reserve、持久 dispatch、严格校验、真实 billed calls 结算、ready/apply 恢复。
  已保存的合法结果按当前任务身份复用，异 key 不产生重复生成。
- `reference_state` 仅保存内容身份摘要、generation ID、结果和各轮查看时间；不重复保存大输入。
  输入仍由 claim 返回的服务器快照提供，避免合法大内容在已计费后撞上保存上限。
- 题目或模式变化清除旧参考。中断的 claimed/reserved 工作在失效时被封闭并立即释放预留；
  dispatched/ready 工作保留结算与恢复，只丢弃已不属于当前题目的结果。
- 删除学习项抹除关联参考；旧 reveal 回执不能复活正文。删除会话或账号继续沿用级联删除。
- 新 trigger 固定 `search_path=pg_catalog`，按被更新行的 owner/session 限定操作，无直接公共执行权限。

## 数据导出与升级顺序

新增迁移 `0037-practice-reference.sql`、`0038-reference-account-exports.sql`，分别与 Supabase 的
`20260913110000_practice_reference.sql`、`20260913120000_reference_account_exports.sql` 字节一致。
两者都在既有 0036 后执行；不重写历史迁移。

完整账号导出新增格式 v4：practice-session 保留原 session/teaching，并增加 nullable `reference`，只包含
结果和查看事实。generation ID、摘要、lease、请求和配额不进入导出。v1/v2/v3 schema 保持冻结，旧 worker
claim 函数不能领取 v4 任务；新 worker 使用 `claim_account_export_v4`。Web 新建导出请求 v4，仍能查看、
重试和下载已有旧格式任务。

部署前必须单独授权并验证迁移，之后 API → Web 串行更新。此次修复测试未执行远端迁移或部署，未调用真实模型，
没有改变 kill switch、Cron、供应商配置或运行时依赖。真实模型语义效果和 Hosted 页面需在相应授权后验收。

## 同批截图问题

收集箱的 structured `Accept` 值会触发浏览器 CORS 预检。API 将 `Accept` 加入允许请求头，保持既有固定
origin 和内部路由限制；读取失败时不再同时显示首次使用空态。

学习库「表达与句型 / 生词」使用具有 44px 最小点击高度的分组导航，保留真实链接、键盘操作和 `aria-current`。

练习教学信息只按 session、业务版本和控制版本判断有效性。独立草稿版本变化不失效教学缓存、不重复读取题目；
同时保留真正业务状态冲突的一次有界重读，避免每次自动保存都闪出加载页面。

## 离线验证

回归覆盖浏览器真实跨域预检、收集箱刷新恢复、逐字输入/自动保存、参考展开与键盘操作、迟到请求与恢复、
同/异幂等键、quota/kill switch、已计费结果恢复、回合和模式变更、目标删除与 owner 隔离、v1–v4 导出/worker
格式隔离。PGlite 用例执行真实迁移、RLS 和 SQL，但不替代真实 PostgreSQL 多连接锁竞争验证。
