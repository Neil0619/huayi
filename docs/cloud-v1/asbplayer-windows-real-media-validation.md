## Windows 真实 YouTube 学习

参考 Mac 已记录的启动条件，在 Windows 以普通进程启动 CfT 149、新建隔离 Profile、指定
localhost 非零调试端口，再连接 CDP；没有 Playwright 默认启动参数、伪装浏览器状态、导入日常
Profile 或注入字幕。初始停用学习模式的对照中，真实英文 timedtext 为 HTTP 200／77,614 字节，
CC 开启、原生字幕可见，证明本机此条件下字幕前置可用；旧的 200／0 字节失败仍保留。

全站 `context.route` 放行对照在重载及另一首次导航中仍出现英文 200／0 字节。最终只拦截已配置
测试 Provider 的域名并返回合成 SSE，YouTube 页面、媒体、字幕不经测试响应替换；英文学习层
可用。Profile 与访问时刻不同，这些观察不足以证明空响应的唯一根因。
没有配置真实模型凭据、云账号或外部词典，不拦截 YouTube 的自然导航和广告响应。

正片；后续核对实际播放器视频身份、非广告状态及英文层，同时有界等待并点击实际可用的 Skip ad。

其他保留的探针错误包括最初误选内置扩展 Worker、切回后台设置页未先取得焦点。正式流程已
