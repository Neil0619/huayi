## 行为

- 「打开缓存视频」选择已有 `.浏览器.mp4`，校验相邻缓存记录和字幕后直接使用；
  原片可以不存在，不调用 FFmpeg 或 ffprobe。任意 MP4、缺失/被修改的缓存明确拒绝。
- 「选择原视频」继续优先复用完整有效缓存，显示「已找到缓存，直接使用」。
  原文件、现有用户文件和损坏缓存不被覆盖。
- 准备好后直接「开始学习」，删除复制路径和授权目录步骤。仅为选中的缓存签发
  有界只读本机 Range 流，不先下载整集生成 Blob；原有字幕选择、批量和换片保留。
- Chrome 首次仍可能要求官网访问本机服务的网站权限。拒绝时显示「重试本机播放」，
  授予后可恢复；没有修改浏览器安全设置或增加 Manifest 权限。
