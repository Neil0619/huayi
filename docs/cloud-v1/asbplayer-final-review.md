## 已复现并修复

1. 英文 Windows CI 的 `WScript.Shell.Save()` 无法保存中文快捷方式；本机用系统代码页外的
   桌面目录复现。改为 Unicode `IShellLinkW` / `IPersistFile`，保留新旧入口所有权核对。
2. Windows PowerShell 5.1 按本机代码页读取 UTF-8 配置，含中文和特殊字符的 Node 路径无法启动。
   真实可执行文件夹具先失败，明确 `-Encoding UTF8` 后 `.lnk` 启动成功。两项实现提交为 `555cfe9`。
3. 缓存清单为空、缺少视频/字幕、重复视频、类别错误或缺少处理计划时，旧代码仍可能返回成功。
   六项回归先失败再修复；现在检查完整计划与文件集合，不把不完整缓存交给播放器。

缓存仍按既有设计保留成功副本，不自动删除用户已有缓存；这是磁盘占用策略，不承诺零副本或
只保存音频。原文件保持只读，当前容量和手动清理方式见[打开器说明](asbplayer-local-opener.md)。
