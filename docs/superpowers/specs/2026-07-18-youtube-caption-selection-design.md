# YouTube 英文字幕取词设计

## 目标与边界

在普通 YouTube `/watch` 录播视频中，为人工或自动英文字幕提供稳定、准确的完整句取词入口。
覆盖普通、剧院和全屏模式，不支持直播、Shorts、OCR 或持久字幕历史。

功能不调用要求 OAuth 和视频编辑权限的 YouTube Data API，也不新增 Chrome 权限。Content
Script 先观察 YouTube 已渲染的字幕 DOM，并在首次发现英文字幕后，从当前 `/watch` 文档的
内嵌播放器响应中尽力解析字幕轨地址。SPA 导航后的现存 DOM 若只保留启动脚本，则匿名重新
获取同一个当前 `/watch` 文档并只解析响应文本。未公开的页面和 timedtext 格式不是稳定契约；
解析、网络或校验失败时必须静默回退到本地字幕缓冲，普通网页划词必须继续工作。

## 交互

Huayi 在 YouTube CC 按钮旁显示“译”按钮。没有当前英文字幕、处于广告或直播状态时按钮禁用。
用户点击后：

1. Huayi 同步调用 `video.pause()`；若视频原本播放则记录需要恢复，原本暂停则不记录。暂停后
   最多等待一个动画帧让字幕 DOM 稳定，不调用 `play()`、不固定等待 2.5 秒，也不等待预取。
2. `YouTubeCaptionContextSource.freeze()` 同步冻结此刻可用的最佳字幕，显示为播放器底部居中
   的 Shadow DOM 卡片；冻结后异步预取结果不得改写卡片文本。
3. 单击准确选择单词；按住鼠标跨单词拖动选择连续短语；“整条字幕”选择冻结的字幕句子。
4. “解释｜翻译”工具条、加载状态和结果卡锚定触发操作时的鼠标位置：点词使用单击位置，
   拖选使用松开位置，“整条字幕”使用该按钮的点击位置；浮层水平中心与该位置对齐，优先
   向上展开，空间不足时换边并钳制在视口内。键盘激活时回退到对应按钮中心。结果卡仍可
   拖动。
5. 冻结卡片保留字幕和选中高亮，允许在同一次暂停中连续查询其他单词。

再次点击处于激活状态的“译”、“继续播放”、关闭和 Escape 使用同一关闭路径结束取词。
只有 Huayi 主动暂停的视频会恢复。用户主动播放、拖动进度、视频结束、播放器被替换或离开
`/watch` 时，界面和活动请求立即清理且不强制播放。

## 文本与请求

`YouTubeCaptionContextSource` 对外接口限定为：

- `attach(player, video, onAvailabilityChange)`：连接当前播放器，观察字幕并后台尽力预取；
- `freeze()`：同步返回当前最佳 `CaptionSnapshot`；
- `clear()`：中止请求并清理全部内存状态。

`freeze()` 的固定优先级是：已完成且与当前 DOM 字幕可靠匹配的整轨字幕句子；最近 30 秒、
最多 2,000 字符的滚动字幕缓冲；当前可见字幕。播放期间按文本重叠去重 DOM 快照并记录
`video.currentTime`。缓冲从最近句末向当前 cue 拼接，只能包含已经观察到的上文和当前 cue；
不能用尚未播放且尚未取得的后文补句。

当前可见 `.ytp-caption-segment` 必须有可见布局框；按视觉顺序合并后规范空白并拒绝汉字。
分词优先使用 `Intl.Segmenter("en", { granularity: "word" })`，并合并英文单词内部的撇号和
连字符；回退正则保持相同边界。最终上下文始终限制为 2,000 字符。

合成请求继续使用 wire v6：

- `selection` 是选中的单词、连续范围或整条当前字幕；
- `context` 是冻结字幕；
- `selectionKind` 使用既有分类器；
- 单词和短语的 `sentenceContext` 是冻结字幕；
- 仅单词的 `wordbookContext` 是冻结字幕。

YouTube 页面标题属于普通网页选区，不进入冻结字幕流程。标准 `h1` 至 `h6` 标题作为有界语义
文本块参与既有句子提取，因此标题内单词可携带完整英文标题作为 `sentenceContext` 和
`wordbookContext`，继续显示欧路生词本动作；该规则同样适用于其他网页的标准标题，不采集
YouTube 页面元数据或更大的自定义容器。

进入取词只发送既有无页面数据 `warmup`。只有点击解释或翻译才发送上述文本；单词结果继续
复用既有欧路查词和显式加入流程。

## 实现与安全

YouTube 选择器、SPA 事件、字幕观察、播放器状态和 UI 全部隔离在 Extension 的 YouTube 模块。
普通网站不创建该观察器。Control、冻结卡和结果使用原生 DOM、开放 Shadow DOM 与
`textContent`，不使用远程代码或 `innerHTML`。

整轨预取只解析当前文档或匿名重新获取的当前 `/watch` 文档文本中的内嵌播放器响应，不执行
其中的脚本，也不访问页面 JavaScript 全局对象。文档重新获取只允许带非空 `v` 参数的 HTTPS
YouTube `/watch` URL，使用 `credentials: "omit"` 且响应最多 2 MiB。优先人工英文轨，其次
自动英文轨。字幕轨请求必须满足全部限制：

- URL 使用 HTTPS，主机属于 YouTube，路径严格为 `/api/timedtext`；
- `v` 参数必须与当前 `/watch` 视频一致；SPA 残留的旧视频轨直接丢弃并重新获取当前文档；
- `credentials: "omit"`，不带 Cookie，超时 3 秒；
- 响应体最多 2 MiB，解析后的 cue 最多 50,000 条；
- 时间和文本字段严格校验；当前时间附近的候选 cue 必须与可见字幕有可靠文本重叠。

验证通过后，按当前播放时间定位 cue，并向前后拼接到英文句界；没有句末时按现有上下文规则
裁剪为最多 2,000 字符。任何页面格式、URL、语言、网络、超限或匹配失败都丢弃整轨结果，
立即沿用缓冲或可见字幕，不影响现有取词。

结果浮层通过可选展示策略解析实时锚点和挂载节点：普通模式挂载文档根节点；全屏模式挂载
`document.fullscreenElement`。默认展示策略保持普通网页现有行为。

整轨和最近 30 秒字幕缓冲只存在于当前 Content Script 内存，不写入 Extension storage、Host
或磁盘。切换视频、播放器替换、字幕语言变化、广告、直播或模块销毁时清空全部状态；seek
只清空滚动缓冲，同一视频已验证的字幕轨可以保留。不记录 URL、标题、字幕、查询或结果，
不把字幕发送给 warmup。Native Host、Provider、凭据、wire v6、Manifest 权限、版本 `0.12.0`
和 `schemaVersion: 6` 均不变。

## 验收

默认离线测试覆盖跨 DOM cue 的 30 秒缓冲拼句、整轨完整句优先、pending/超时/格式错误/超限/
非 YouTube URL/字幕不匹配回退、2,000 字符上限、立即暂停和单动画帧稳定、seek/SPA/播放器/
语言/广告/直播清理，以及既有分词、连续取词、定位、全屏和普通网页回归。Playwright 使用本地
YouTube DOM fixture 模拟上下半句与整轨成功/失败，验证冻结卡、最终分析上下文和无字幕数据
warmup；真实 YouTube/Chrome 验证需单独授权。
