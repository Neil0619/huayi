# YouTube 英文字幕取词设计

## 目标与边界

在普通 YouTube `/watch` 录播视频中，为当前可见的人工或自动英文字幕提供稳定、准确的取词
入口。覆盖普通、剧院和全屏模式，并在 YouTube 按时间切分一句话时用已经渲染的相邻 cue
恢复当前英文句。不支持直播、Shorts、OCR、整段字幕下载、transcript 或字幕历史。

功能只读取 YouTube 已渲染的当前字幕 DOM，不调用 YouTube Data API，不申请 OAuth，也不新增
Chrome 权限。YouTube DOM 适配失败时功能静默不可用，普通网页划词必须继续工作。

## 交互

Huayi 在 YouTube CC 按钮旁显示“译”按钮。没有当前英文字幕、处于广告或直播状态时按钮禁用。
用户点击后：

1. 当前已经组装的目标句立即显示为播放器底部居中的 Shadow DOM 卡片。
2. 若播放中的目标句没有可靠句尾，视频继续播放且卡片实时补充文本，最多等待 2.5 秒；此时
   卡片标记忙碌，点词、拖选和整句动作禁用，但关闭、Escape 和再次点击“译”仍可取消。
3. 遇到句尾或超时后，Huayi 固定目标文本并暂停仍在播放的视频。原本暂停的视频立即固定为
   当前最佳文本，不为取得后续字幕自动播放。
4. 单击准确选择单词；按住鼠标跨单词拖动选择连续短语；完整结果使用“整句字幕”，超时退化
   使用“当前字幕”并明确提示没有检测到完整句尾。
5. “解释｜翻译”工具条、加载状态和结果卡锚定触发操作时的鼠标位置：点词使用单击位置，
   拖选使用松开位置，整句操作使用该按钮的点击位置；浮层水平中心与该位置对齐，优先
   向上展开，空间不足时换边并钳制在视口内。键盘激活时回退到对应按钮中心。结果卡仍可
   拖动。
6. 冻结卡片保留字幕和选中高亮，允许在同一次暂停中连续查询其他单词。

再次点击处于激活状态的“译”、“继续播放”、关闭和 Escape 使用同一关闭路径结束取词。
只有 Huayi 主动暂停的视频会恢复。用户主动播放、拖动进度、视频结束、播放器被替换或离开
`/watch` 时，界面和活动请求立即清理且不强制播放。

## 文本与请求

当前可见 `.ytp-caption-segment` 必须有可见布局框；按视觉顺序合并后规范空白、拒绝汉字和超过
2,000 字符的内容。分词优先使用 `Intl.Segmenter("en", { granularity: "word" })`，并合并英文
单词内部的撇号和连字符；回退正则保持相同边界。

Extension 在页面内存维护最近 20 秒、最多 16 次有效观察和最多 2,000 字符的当前句状态。完全
重复和回滚快照不重复追加；前缀增长、可信的旧后缀/新前缀重叠以及自动字幕尾部修订被合并。
超过 4 秒的间隔和 `>>` 说话人标记建立硬边界。句界优先使用
`Intl.Segmenter("en", { granularity: "sentence" })`，回退规则识别句末标点并排除小数、
首字母缩写和常见英文缩写。点击目标绑定到点击时最新 cue 所属的最后一句，后续只补到第一个
句末；同一快照中的下一句不会展示或发送。超限保留最后一个合法目标并按退化结果固定。

合成请求继续使用当前 wire v6：

- `selection` 是最终目标句内选中的单词、连续范围或整句；
- `context` 是最终目标句；
- `selectionKind` 使用既有分类器；
- 单词和短语的 `sentenceContext` 是同一目标句；
- 仅单词的 `wordbookContext` 是同一目标句。

YouTube 页面标题属于普通网页选区，不进入冻结字幕流程。标准 `h1` 至 `h6` 标题作为有界语义
文本块参与既有句子提取，因此标题内单词可携带完整英文标题作为 `sentenceContext` 和
`wordbookContext`，继续显示欧路生词本动作；该规则同样适用于其他网页的标准标题，不采集
YouTube 页面元数据或更大的自定义容器。

进入取词只发送既有无页面数据 `warmup`。只有点击解释或翻译才发送上述文本；单词结果继续
复用既有欧路查词和显式加入流程。

## 实现与安全

YouTube 选择器、SPA 事件、字幕观察、播放器状态和 UI 全部隔离在 Extension 的 YouTube 模块。
普通网站不创建该观察器。Control、冻结卡和结果使用原生 DOM、开放 Shadow DOM 与
`textContent`，不使用远程代码或 `innerHTML`。

结果浮层通过可选展示策略解析实时锚点和挂载节点：普通模式挂载文档根节点；全屏模式挂载
`document.fullscreenElement`。默认展示策略保持普通网页现有行为。

不持久化或记录 URL、标题、字幕、查询或结果。字幕缓冲只存在于当前页面内存；seek、广告、直播、
播放器替换、视频导航、离开 `/watch` 和销毁都会清空。补全期不发送字幕，warmup 仍无页面
数据；只有用户在文本固定后点击解释、翻译或显式加入欧路才发送最终目标句。本功能不改变
Native Host、Provider、凭据或 Manifest 权限；整合基线继续使用版本 `0.12.0` 和
`schemaVersion: 6`。

## 验收

默认离线测试覆盖可见字幕读取、动态节点、英文过滤、跨 cue 去重和修订、句界/超时/容量边界、
补全期只读卡片、精确目标句上下文、智能暂停恢复、连续取词、竞态清理、鼠标位置锚定、“译”
按钮切换关闭、优先向上定位、全屏重挂载和普通网页回归。
Playwright 使用本地 YouTube DOM fixture 验证真实 Content Script、Service Worker、请求
协调器和 fake Native Host 全链路；真实 YouTube/Chrome 验证需单独授权。
