# v0.12.0 浮层编辑词典视觉设计

## 目标

把划译从蓝白 SaaS 工具面板改造成阅读场景中的轻量编辑词典卡。视觉改造不能改变 wire v6、
Provider、模型请求、欧路数据、Chrome 权限或结果语义，也不新增网络请求或模型字段。

设计参考以下成熟模式：DeepL 使用紧贴阅读上下文、可拖动的小窗口；Apple 建议浮层只承载少量
相关任务、避免过大并平滑处理尺寸变化；Carbon 要求单一浮层、完整键盘操作并避免嵌套浮层。

## 视觉系统

- 全部视觉值从 Overlay token 扩展：暖纸色 `paper`、深墨色 `ink`、暖灰 `muted`、陶土色
  `terracotta`、细分隔线和暖灰低透明阴影；不得回退到廉价蓝白 SaaS 观感。
- 结果卡使用单一暖纸表面，宽度上限 420px、圆角 16px，不在结果项外重复套卡片。
- 顶部模式标题降为带字距的次要标签；单词源词使用衬线词典头部，音标紧随其后。
- 模型的语境义或语境解析使用浅陶土纸色和左侧强调线；网页原句使用独立的暖灰语境条。
- 常见释义使用词性胶囊与释义行；短语、词形和用法使用左右结构化行；易混词和同义词使用
  双列对照，320px 下退化为单列。

## 完成页面结构

- 选词操作条先显示用户选中的原文，再显示有主次层级的动作卡。单词、短语和句子依
  `supportsAction` 显示解释与翻译；只有段落只显示翻译。解释说明随 selection kind 区分原句
  用法或句子结构，翻译说明区分词典释义、短语搭配、句子或段落翻译。
- 翻译与解释结果共用 `sticky header -> lexical/source header -> 原句语境 -> 模型结果板块` 的
  阅读顺序。原句语境位于 lemma 下方，优先使用 `sentenceContext`，不可用时再使用 `context`；
  选中文本由安全 DOM text node 与 `mark` 高亮，禁止 `innerHTML`。
- 顶部 sticky header 保留模式标签、拖动、关闭和生词本动作。生词本必须继续紧邻顶部词头区域，
  不得移到正文底部；这是用户明确覆盖过的产品约束。按钮在 loading/streaming 即可用并随查询、
  添加和完成状态原位 patch，后台写入生命周期与关闭行为不得因视觉结构改变。

## 流式与状态

- 继续按 `data-huayi-section` 键控 patch，源词、音标、板块和数组项不得因增量更新整卡替换。
- 加载态立即显示源词和原句语境，并以细规则、状态文字和三行编辑词典骨架占位；不显示独立大块
  spinner 面板。加载和单词流式阶段保留 208px 最小正文高度，降低前几个板块到达时的纵向跳动。
- 新节点只执行一次 120ms 淡入和 3px 位移；`prefers-reduced-motion` 下禁用动画与过渡。
- `source`、`source-context` 与现有 `data-huayi-section` 模型板块都原位 patch；loading、streaming
  和 result 之间不得整卡替换。最终空板块继续隐藏；错误预览、生词错误、重试、焦点、滚动和
  拖动语义保持不变。

## 无障碍与窄屏

- Escape、键盘拖动、可见焦点和视口约束保持现有行为。
- 320px 下卡片宽度为视口减 16px；短语与辨析改为单列，头部生词、拖动和关闭控件不得重叠。
- 所有网页与模型文本仍只使用 `textContent`；SVG 仅包含固定本地图标路径。

## 非目标

- 不增加暗色模式、设置页、朗读、复制、折叠区、侧边栏或第二种主题。
- 不修改单词、短语、句子或段落的模型契约和字段顺序。
- 不执行真实模型 smoke；本版只需离线测试、浏览器视觉回归、构建和本机同步替换。
